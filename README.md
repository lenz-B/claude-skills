# lenzb-claude-skills

A collection of Claude skills built for personal brand and content operations.

## Skills

- **anti-ai-writing** — strips AI patterns from any written output
- **design-loop** — iterative design build/critique loop
- **design-taste-frontend** — senior UI/UX engineering standards
- **full-output-enforcement** — forces complete, untruncated outputs
- **model-router** — recommends the right Claude model tier for a task
- **ponytail-audit** / **ponytail-review** — audit and review passes
- **powershell-windows** — PowerShell on Windows without the footguns
- **prompt-forge** — turns rough thoughts into high-performance prompts
- **skill-creator-enhanced** — build, test, and improve Claude skills
- **verification-before-completion** — evidence before claiming done
- **visual-engineer** — pick the right visual form for data and concepts, then build it
- **yt-transcript** — YouTube captions to transcript and timings

## How to use

Each skill lives in its own folder. Drop the folder into `/mnt/skills/user/` on your Claude setup and add the trigger description to your skills list.
